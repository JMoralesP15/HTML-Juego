# QUÉ AÑO v1.6 — Screen Spec

## Resultado cerrado

**Jerarquía:** título → `estimación → año real` → diferencia → aprendizaje esencial → `Profundizar` → `Siguiente`.

El aprendizaje esencial usa hasta tres bloques: `Qué fue`, `Por qué importa`, `Dato para recordar`. Sólo aparecen cuando hay información real en el banco editorial. La ubicación temporal no aparece en esta capa.

## Resultado expandido

`Profundizar` revela, dentro de la misma pantalla: contexto completo, relevancia adicional, ubicación temporal secundaria, imagen útil y fuente/licencia. No muestra estados internos como `Referencia heredada`, versión de la lámina o pendientes editoriales.

## Resumen final

Orden: resultado global → métricas secundarias → `Qué aprendiste hoy` → `Para tu próximo repaso` → acciones secundarias. El CTA de repaso se eleva antes de navegación secundaria.

## Móvil

Durante pregunta y resultado se oculta la navegación global. Resultado y aprendizaje se apilan en una sola columna. El contexto puede hacer scroll; `Siguiente` permanece sticky por la capa v1.5.

## Conservación

No tocar timer absoluto, CTA Confirmar, LocalStorage, Sets, Repaso, Learning Gain, Commons, analytics, IDs, años ni calendario.
